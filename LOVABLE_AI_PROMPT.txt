Build me a professional frontend for Catchers AI - an advanced threat detection and phishing analysis platform.

🎯 PROJECT OVERVIEW:
I have a fully functional backend API (Node.js + ML service) that analyzes URLs and files for security threats using multiple threat intelligence sources (VirusTotal, Google Safe Browsing, PhishTank) and a Machine Learning model (96% accuracy). I need you to build ONLY the frontend that connects to this existing API.

🔗 BACKEND API DETAILS:

Base URL: http://localhost:3000 (development)

Main Endpoint - Analyze URL:
POST /api/v1/threats/analyze-url
Body: { "url": "https://example.com" }

Response includes:
- threatScore (0-100)
- riskCategory (LOW, MEDIUM, HIGH, CRITICAL)
- recommendation (text advice)
- aiAnalysis (detailed AI explanation)
- riskFactors (array of detected issues)
- securityFeatures (array of positive features)
- detectionMethods (results from VirusTotal, Google Safe Browsing, PhishTank, ML model)
- technicalDetails (domain age, SSL status, WHOIS data, redirects)
- explainability (ML feature importance)
- processingTime

Other Endpoints:
- POST /api/v1/threats/analyze-file (for file analysis)
- GET /api/v1/threats/history?limit=50&skip=0&riskCategory=HIGH
- GET /api/v1/threats/statistics
- GET /health
